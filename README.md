# medCare — Medzoos Mobile App

React Native customer app for **Medzoos** (Android & iOS).

## Quick start

```bash
npm install
npm start
# separate terminal:
npm run android   # or npm run ios
```

Requires the **Backend** running on port 5000. Configure API URL in `src/config/api.ts`.
